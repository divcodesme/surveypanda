# Security Policy

## Reporting Vulnerabilities

Please report suspected security vulnerabilities privately to the project maintainers. Do not open a public issue for vulnerabilities.

Include:

- Affected area or endpoint.
- Steps to reproduce.
- Potential impact.
- Suggested mitigation, if known.

## Security Priorities

- Public survey links must be unguessable.
- Public response submission must be validated server-side.
- Personal data collection should be intentional and minimized.
- Creator and respondent permission boundaries must be enforced by the API.
